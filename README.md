# 薬棚AI検索：1店舗・ログイン不要共有版

検索・登録・修正・削除はすべてログイン不要。Supabaseで全端末に共有し、開いている画面は約20秒ごとに更新します。

## 設置
1. Supabaseで新規プロジェクトを作り、SQL Editorで `schema.sql` を実行。
2. Project URLと**公開用anon/publishableキー**を `config.js` に設定。service_role/secretキーは絶対に記載しない。
3. `index.html`, `config.js`, `sample-shelf.jpg` をGitHubリポジトリにアップロードしてGitHub Pagesを有効化。
4. 公開URLを開き、棚写真を登録。「OCRで仮登録」で候補を生成し、位置と薬品名・規格を現物と照合して確認登録。

## 重要な注意
- **URLを知る第三者もデータの閲覧・改ざん・削除が可能です。** URLを非公開にするだけではアクセス制御になりません。インターネット公開運用は推奨しません。院内限定ネットワークや認証を使う方式がより安全です。
- 認識エンジンはTesseract.jsの日本語OCR。写真の小さなラベルは認識ミスや見落としが多く、医薬品名を確実に同定するAIではありません。
- 未確認の候補は検索結果には標準で出ません。「未確認も表示」でレビューできます。
- 棚写真に患者氏名、処方箋、個人情報などが写らないようにしてください。
- 誰でも編集できるため、定期的なデータバックアップを推奨します。現バージョンには自動バックアップ・変更履歴はありません。
- 画像の更新後は既存の位置座標を再確認してください。
