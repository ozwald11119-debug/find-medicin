# 薬棚AI検索（試作版）

## 公開方法
このフォルダの `index.html` と `sample-shelf.jpg` をGitHubリポジトリのルートにアップロードし、Settings → Pages → Deploy from a branch → main / root を選択してください。公開URLにアクセスすると利用できます。

## 基本操作
1. 「サンプル写真を読み込む」または棚の写真をアップロード。
2. 「AI-OCR候補抽出」を実行。文字列と矩形の候補が未確認状態で登録されます。
3. 各候補の薬品名・規格・場所を修正し「確認して登録」。
4. 薬品名で検索し「場所を見る」で写真内を強調表示。
5. JSONを書き出してバックアップ。別端末ではJSONを読み込み。

## 制限と安全
- AI-OCRはTesseract.js（ブラウザ内処理）であり、医薬品専用の画像理解AIではありません。小さい文字や規格の読み違い、薬品以外の文字列の検出があり得ます。
- 未確認候補は通常の検索結果に出ません。
- 写真・データはlocalStorage保存。端末間自動同期なし。画像枚数が多いと容量不足になります。
- OCR初回はCDNと学習データのダウンロードが必要です。ネットワーク制限下では動作しない場合があります。
- 本番導入にはログイン、権限管理、中央DB、変更履歴、画像ストレージ、定期バックアップを推奨します。
- 棚位置の検索結果は調剤の正確性を保証しません。薬品名・規格・剤形・現物の確認は必須です。
